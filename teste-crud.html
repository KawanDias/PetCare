🐾 Teste Rápido do CRUD PetCare

💡 Dica: Abra o Console do navegador (F12 ou Ctrl+Shift+I) para ver os resultados dos comandos

1️⃣ Adicionar Pets de Teste

Clique para executar e adicionar 3 pets de exemplo ao localStorage

// Adiciona 3 pets de exemplo pets = [ { nome: 'Rex', especie: '🐶', idade: 3, vacinacao: 'Em dia', data: '2025-12-15', descricao: 'Cachorro muito dócil', emoji: '🐶' }, { nome: 'Luna', especie: '🐱', idade: 2, vacinacao: 'Em atraso', data: '2024-06-10', descricao: 'Gata carinhosa', emoji: '🐱' }, { nome: 'Hoppy', especie: '🐰', idade: 1, vacinacao: 'Em dia', data: '2025-10-01', descricao: 'Coelho branco', emoji: '🐰' } ] localStorage.setItem('petsCrud', JSON.stringify(pets))

2️⃣ Visualizar Pets Salvos

Clique para ver todos os pets salvos no console

pets = JSON.parse(localStorage.getItem('petsCrud') || '[]') console.log('Pets salvos:', pets)

3️⃣ Limpar Todos os Dados

Clique para apagar todos os pets e começar do zero

localStorage.removeItem('petsCrud') console.log('Dados apagados!')

4️⃣ Editar um Pet

Execute no console para editar o primeiro pet

pets = JSON.parse(localStorage.getItem('petsCrud') || '[]') if (pets.length > 0) { pets[0].idade = 5 pets[0].vacinacao = 'Em atraso' localStorage.setItem('petsCrud', JSON.stringify(pets)) console.log('Pet editado:', pets[0]) }

5️⃣ Deletar um Pet

Execute para remover o último pet da lista

pets = JSON.parse(localStorage.getItem('petsCrud') || '[]') if (pets.length > 0) { const deletado = pets.pop() localStorage.setItem('petsCrud', JSON.stringify(pets)) console.log('Pet deletado:', deletado) }

6️⃣ Contar Pets

Clique para saber quantos pets você tem

pets = JSON.parse(localStorage.getItem('petsCrud') || '[]') console.log('Total de pets:', pets.length)

7️⃣ Pesquisar Pet por Nome

Pesquisa um pet pelo nome

pets = JSON.parse(localStorage.getItem('petsCrud') || '[]') const nome = 'Rex' // Mude para o nome desejado const pet = pets.find(p => p.nome.toLowerCase() === nome.toLowerCase()) console.log('Pet encontrado:', pet || 'Não encontrado')
⚠️ Aviso: Os dados são salvos em localStorage do navegador. Se você limpar o cache, todos os dados serão perdidos!
